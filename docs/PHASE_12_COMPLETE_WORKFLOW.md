This document describes the complete end-to-end workflow for SORTED.

1. Google Login (Operator session creation)
2. DigiLocker Gateway (Blocks unverified users)
3. DigiLocker OAuth & Consent
4. Synchronize documents & build Citizen Profile
5. View Dashboard with personalized eligible schemes
6. Run pre-submission health checks
7. Resolve mismatches and submit application.
